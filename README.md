# Apple Insights 2026

> **Studieprojekt, Multimediedesign, Erhvervsakademi Aarhus. Ikke tilknyttet Apple.**
>
> Eksamensprojekt i Dynamic User Interface, lavet af Sebastian, Daniel og Martin. Det er ikke et produkt fra Apple, og alle tal i appen er testdata.

**Se projektet:** [appleinsights.dk](https://appleinsights.dk)

Apple Insights er en årsopsummering af din iPhone, inspireret af Spotify Wrapped. Den åbnes fra Indstillinger og fortæller om dit 2026 i tre kapitler: Skærmtid, Fotos og Sundhed.

Bygget med Next.js, React, Supabase, Motion og Rive.
